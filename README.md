this Application build using python PyQt5 and Raspberry Pi 4b

This application works by connecting the camera to the Raspberry Pi and sensor. When the sensor is active, the camera will take a picture and then the picture will be detected with the previous YOLOv7 training results. If successful, it will be counted. If it fails, it will be a failure.
